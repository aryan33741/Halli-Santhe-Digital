# Halli-Santhe Digital 🛍️

Halli-Santhe Digital is an Android-based marketplace application developed to support local artisans and promote traditional handmade products through a digital platform.

The application allows buyers to browse handcrafted items such as Channapatna toys, clay pots, handmade bags, and bamboo baskets, while artisans can upload and showcase their products easily.

---

## ✨ Features

- Product Listing using RecyclerView
- Product Detail Screen
- Search Functionality
- Artisan Upload Module
- Modern Dark UI
- Firebase Integration
- Glide Image Loading
- Responsive Grid Layout
